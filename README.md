# From the day I met you ❤️

Una app móvil para llevar la cuenta del tiempo desde que conociste a alguien especial.

## Características

- Actualización en tiempo real (décadas, años, meses, semanas, días, horas, minutos y segundos)
- Soporte para múltiples contadores
- Funciona completamente **offline**
- Disponible en **5 idiomas**: Español, English, Português, Italiano y Русский
- Se puede instalar como aplicación en el móvil (PWA)
- Diseño oscuro y elegante

## Cómo usarla

1. Abre el enlace en Chrome
2. Toca los tres puntos ⋮
3. Selecciona **"Instalar app"** o **"Añadir a pantalla de inicio"**

## Tecnologías

- HTML + CSS + JavaScript
- Progressive Web App (PWA)
- Service Worker para funcionamiento offline
- Soporte multi-idioma
